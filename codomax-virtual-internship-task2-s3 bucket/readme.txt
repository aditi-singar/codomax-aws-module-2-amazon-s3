# AWS S3 Static Portfolio Website

## 📌 Project Overview
This project demonstrates how to host a static portfolio website using **Amazon Web Services (AWS) S3**. The website is developed using HTML and CSS and deployed through an Amazon S3 bucket.

The main purpose of this project is to understand cloud storage, S3 bucket configuration, object management, access permissions, and static website hosting.

## 🎯 Objectives
- Understand Amazon S3 buckets and objects.
- Create and configure an S3 bucket.
- Upload and manage website files in S3.
- Understand basic S3 access control and bucket policies.
- Deploy a static website using Amazon S3.

## 🛠️ Technologies Used
- **HTML5** – Website structure.
- **CSS3** – Website styling.
- **Amazon S3** – Cloud storage and static website hosting.
- **AWS Management Console** – Bucket configuration and deployment.

## 🌐 Website Features
- Home section
- About Me section
- Technical Skills section
- Projects section
- Amazon S3 Information section
- Contact section
- Responsive website layout

## ☁️ AWS S3 Implementation
The following steps were performed during deployment:

1. Created an Amazon S3 bucket.
2. Configured bucket settings.
3. Uploaded the `index.html` file.
4. Enabled static website hosting.
5. Configured bucket permissions and a bucket policy.
6. Accessed the website using the S3 website endpoint.
